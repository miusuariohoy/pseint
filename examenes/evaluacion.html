A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Qué orden respeta un algoritmo bien estructurado?

Un algoritmo estructurado avanza en pasos claros: declarar, procesar y comunicar el resultado.

2 ¿Qué tipo conviene para guardar el promedio de notas?

El promedio puede tener decimales, por eso se guarda como Real.

3 Para pedir la edad y guardarla, ¿qué par de instrucciones se usa?

Primero se muestra el mensaje con Escribir y después se guarda el dato con Leer.

4 ¿Cuántas veces se ejecuta el bloque de Para i <- 3 Hasta 7 Con Paso 1 Hacer?

El contador toma los valores 3, 4, 5, 6 y 7. El límite Hasta se incluye: son 5 vueltas.

5 En visitas <- visitas + 1;, ¿qué papel cumple visitas?

Un contador suma una cantidad fija (normalmente 1). El acumulador suma valores que pueden cambiar.

B

Predicción de salidas

4 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este algoritmo?

Definir temperatura Como Entero;
temperatura <- 31;
Si temperatura > 30 Entonces
    Escribir "Calor";
Sino
    Escribir "Templado";
FinSi

31 es mayor que 30: se ejecuta la rama del Entonces y la salida es Calor.

7 ¿Qué muestra este algoritmo?

Definir i Como Entero;
i <- 2;
Mientras i < 8 Hacer
    Escribir i;
    i <- i + 2;
FinMientras

El Mientras muestra 2, 4 y 6. Al llegar a 8, la condición se vuelve falsa.

8 ¿Qué muestra este algoritmo?

Definir i Como Entero;
Para i <- 10 Hasta 4 Con Paso -2 Hacer
    Escribir i;
FinPara

El paso negativo hace que el Para descienda de 10 a 4 de dos en dos.

9 ¿Qué muestra este algoritmo?

SubProceso Avisar(mensaje)
    Escribir mensaje;
FinSubProceso

Algoritmo Prueba
    Avisar("Listo");
FinAlgoritmo

El subproceso recibe "Listo" en el parámetro mensaje y lo muestra.

Cómo se corrige la Parte C

Cada actividad vale 1 punto y se evalúa con una lista de requisitos. Si falta un requisito, se descuenta la parte proporcional. El corrector revisa la estructura del pseudocódigo; no ejecuta el programa.

Se revisaEjemplo
Declaración de variables con tipoDefinir edad Como Entero;
Entrada y salidaLeer edad; · Escribir edad;
Condicional completoSi ... Entonces ... Sino ... FinSi
Bucle completoMientras ... Hacer ... FinMientras
Contadores y acumuladores inicializadosaprobadas <- 0; · suma <- 0;

Antes de enviar

  • Declaré todas las variables con su tipo e inicialicé los contadores antes de usarlos.
  • Cerré cada Si, Mientras, Para y SubProceso.
  • Inicialicé los contadores antes de usarlos.
  • Probé mentalmente el algoritmo con un caso chico.
  • Revisé que las salidas coincidan con lo pedido.

10 Leé una temperatura. Si es 30 o más, mostrá Alta; si no, mostrá Normal. Usá Si … Entonces … Sino … FinSi.

VariablesLeer / EscribirCondicional

Ver pista

Declará temperatura como Real, leela antes del Si y escribí un mensaje distinto en cada rama.

Ver una solución de referencia 
Algoritmo ControlTemperatura
    Definir temperatura Como Real;
    Escribir "Ingresá la temperatura:";
    Leer temperatura;
    Si temperatura >= 30 Entonces
        Escribir "Alta";
    Sino
        Escribir "Normal";
    FinSi
FinAlgoritmo

11 Pedí 5 notas con un Mientras. Contá cuántas son mayores o iguales que 6 en aprobadas y sumá todas en suma. Mostrá ambos resultados.

MientrasContadorAcumulador

Ver pista

Inicializá aprobadas y suma en 0, repetí 5 vueltas con i, leé cada nota, sumala siempre y aumentá aprobadas solo si corresponde.

Ver una solución de referencia 
Algoritmo ResumenNotas
    Definir nota, aprobadas, suma, i Como Entero;
    aprobadas <- 0;
    suma <- 0;
    i <- 1;
    Mientras i <= 5 Hacer
        Escribir "Ingresá una nota:";
        Leer nota;
        suma <- suma + nota;
        Si nota >= 6 Entonces
            aprobadas <- aprobadas + 1;
        FinSi
        i <- i + 1;
    FinMientras
    Escribir "Aprobadas: ", aprobadas;
    Escribir "Suma: ", suma;
FinAlgoritmo
