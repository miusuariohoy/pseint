Parte C · Soluciones (3 puntos)

Actividad 1

Leé una temperatura . Si es 30 o más, mostrá Alta ; si no, mostrá Normal . Usá Si … Entonces … Sino … FinSi .

Algoritmo ControlTemperatura
    Definir temperatura Como Real;
    Escribir "Ingresá la temperatura:";
    Leer temperatura;
    Si temperatura >= 30 Entonces
        Escribir "Alta";
    Sino
        Escribir "Normal";
    FinSi
FinAlgoritmo

Actividad 2

Pedí 5 notas con un Mientras . Contá cuántas son mayores o iguales que 6 en aprobadas y sumá todas en suma . Mostrá ambos resultados.

Algoritmo ResumenNotas
    Definir nota, aprobadas, suma, i Como Entero;
    aprobadas <- 0;
    suma <- 0;
    i <- 1;
    Mientras i <= 5 Hacer
        Escribir "Ingresá una nota:";
        Leer nota;
        suma <- suma + nota;
        Si nota >= 6 Entonces
            aprobadas <- aprobadas + 1;
        FinSi
        i <- i + 1;
    FinMientras
    Escribir "Aprobadas: ", aprobadas;
    Escribir "Suma: ", suma;
FinAlgoritmo

Actividad 2

Sin usar Para ni Mientras , asigná e1 <- 17; , e2 <- 20; y e3 <- 15; . Con tres Si , contá en adultos cuántas edades son 18 o más y mostrá el total.

Algoritmo ContarAdultos
    Definir e1, e2, e3, adultos Como Entero;
    e1 <- 17;
    e2 <- 20;
    e3 <- 15;
    adultos <- 0;
    Si e1 >= 18 Entonces
        adultos <- adultos + 1;
    FinSi
    Si e2 >= 18 Entonces
        adultos <- adultos + 1;
    FinSi
    Si e3 >= 18 Entonces
        adultos <- adultos + 1;
    FinSi
    Escribir "Adultos: ", adultos;
FinAlgoritmo

Sin usar bucles, asigná g1 <- 12.5; , g2 <- 7.5; y g3 <- 20; . Acumulá los tres gastos en total (inicializado en 0) y mostrá el resultado.

Algoritmo TotalGastos

    g1 <- 12.5;
    g2 <- 7.5;
    g3 <- 20;

        FinSi
    FinMientras

Rúbrica y criterios comunes

El corrector revisa la estructura del pseudocódigo, no lo ejecuta.

BloqueCorrecciónPuntaje
OPCIÓN MÚLTIPLE1 punto por respuesta correcta; sin puntaje parcial.5 o 6
SALIDAS0,5 puntos por salida exacta (se ignoran espacios y mayúsculas).1 o 2
PSEUDOCÓDIGOCada actividad vale 1 punto y se descuenta de forma proporcional por cada requisito incumplido.3
  • Se aceptan Algoritmo o Proceso con su cierre correspondiente.
  • Se aceptan formas equivalentes de las condiciones, por ejemplo >= 18 o > 17 para “18 o más”.
  • En los bucles Mientras se acepta la inicialización del control en 0 o en 1 cuando el número de vueltas es el mismo.
  • En las salidas se aceptan números con coma o con punto decimal.
  • Ante una solución alternativa válida que el corrector no reconozca, el docente puede revisar el código manualmente y ajustar la nota.

Los errores frecuentes son: olvidar el FinSi, FinMientras, FinPara o FinSubProceso; no inicializar contadores y acumuladores; confundir Leer con Escribir; y usar Mientras donde el enunciado pide Para (o al revés).
