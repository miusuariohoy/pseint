Parte C · Soluciones (3 puntos)

Actividad 1 · Nombre y edad

Algoritmo EdadPersona
    Definir nombre Como Caracter;
    Definir edad Como Entero;
    Escribir "Ingresá el nombre:";
    Leer nombre;
    Escribir "Ingresá la edad:";
    Leer edad;
    Si edad >= 18 Entonces
        Escribir nombre, " es mayor de edad";
    Sino
        Escribir nombre, " es menor de edad";
    FinSi
FinAlgoritmo

Requisitos: algoritmo completo, nombre como Caracter, edad como Entero, dos lecturas, Si/Sino/FinSi, comparación con 18 y mensajes con el nombre.

Actividad 2 · 10 edades: mayores y no mayores de 16

Algoritmo ContarEdades
    Definir edad, mayores, menores, i Como Entero;
    mayores <- 0;
    menores <- 0;
    i <- 1;
    Mientras i <= 10 Hacer
        Escribir "Ingresá una edad:";
        Leer edad;
        Si edad > 16 Entonces
            mayores <- mayores + 1;
        Sino
            menores <- menores + 1;
        FinSi
        i <- i + 1;
    FinMientras
    Escribir "Mayores de 16: ", mayores;
    Escribir "No mayores de 16: ", menores;
FinAlgoritmo

Requisitos: variables enteras, dos contadores y i inicializados, Mientras i <= 10, lectura de la edad dentro del bucle, Si/Sino/FinSi con edad > 16, incremento de cada contador en su rama, incremento de i y salida de ambos totales.

Actividad 3 · SubProceso Saludar

SubProceso Saludar(nombre)
    Escribir "Hola, ", nombre;
FinSubProceso

Algoritmo Saludo

FinAlgoritmo

Requisitos: SubProceso Saludar(nombre) y FinSubProceso, saludo con Escribir que incluya el parámetro, algoritmo principal completo y llamada Saludar("Ana").

C

Rúbrica de puntaje

Cómo se distribuyen los 10 puntos

ParteCriterioPuntaje
A · Opción múltiple1 punto por respuesta correcta; sin puntaje parcial.5
B · Salidas0,5 puntos por salida exacta. Se aceptan espacios o comas entre valores.2
C · Programas1 punto por actividad, distribuido entre los requisitos de estructura. Se otorga puntaje proporcional.3
Total10

Errores frecuentes

  • No declarar variables o declararlas con un tipo incorrecto.
  • Olvidar el FinSi, FinMientras, FinPara o FinSubProceso.
  • No inicializar los contadores antes del bucle.
  • No incrementar el contador del Mientras, lo que produce un bucle infinito.
  • Usar = en lugar de <- para asignar.
  • Comparar con = cuando se necesita <> (distinto).
  • No llamar al subproceso desde el algoritmo principal.
  • Confundir contador con acumulador: el contador suma 1; el acumulador suma un valor variable.

Observaciones para la corrección

  • La actividad 2 pide los nombres mayores, menores e i. Si el alumno usa otros nombres coherentes, el docente puede revisar el código manualmente.
  • Se aceptan Caracter o Cadena para textos.
  • Se aceptan Mientras i <= 10, Mientras i < 11, Mientras i < 10 o Mientras i <= 9 para el bucle fijo de 10 vueltas, con i inicializado en 0 o en 1.
  • Se toleran errores de tipeo menores en los nombres declarados (por ejemplo menore por menores).
  • Se aceptan Si edad >= 16, Si edad > 16, Si 16 < edad o Si edad >= 17 para mayores de 16.
  • La lectura de la edad tiene que estar dentro del Mientras; si está afuera se cuenta la misma edad en todas las vueltas.
  • Las variables pueden declararse todas juntas o en varias líneas con Definir.
  • No se distinguen mayúsculas y minúsculas: MIENTRAS, Mientras y mientras son equivalentes.
  • Proceso … FinProceso es equivalente a Algoritmo … FinAlgoritmo.
  • El corrector revisa estructura con expresiones regulares; no ejecuta el pseudocódigo. Ante una solución alternativa válida, el docente puede revisar el código manualmente.
