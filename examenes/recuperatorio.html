Antes de empezar

  • Leé cada consigna con atención y respondé todas las preguntas.
  • En la Parte A marcá una sola opción por pregunta.
  • En la Parte B escribí la salida exacta del algoritmo. Si son varios valores, separalos con un espacio.
  • En la Parte C escribí el pseudocódigo completo en PSeInt estricto. El corrector revisa la estructura, no ejecuta el algoritmo.
  • Usá Definir ... Como ...;, la flecha <- y cerrá cada estructura con su Fin....
  • Podés declarar las variables todas juntas o en varias líneas, y no importan las mayúsculas: MIENTRAS y mientras son equivalentes. Proceso … FinProceso también vale como Algoritmo … FinAlgoritmo.
  • Podés realizar el recuperatorio más de una vez. Cada envío queda registrado con tu apellido, nombre, día y hora.
  • Si otra persona va a usar esta computadora, al terminar presioná Hacer otra evaluación para dejarla lista.
  • Al corregir, la nota y la corrección se guardan automáticamente en el informe del docente.

A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cuál de estas opciones es un ejemplo de selección?

La selección elige entre dos caminos según una condición. Para y Mientras son iteraciones.

2 ¿Qué tipo conviene para guardar la edad de una persona?

La edad se expresa con números enteros, así que se declara como Entero.

3 ¿Qué instrucción muestra el valor calculado en total?

Escribir es la instrucción de salida: muestra en pantalla el contenido de la variable.

4 ¿Qué bucle conviene para seguir leyendo datos hasta que aparezca -1?

No se sabe cuántos datos vendrán: el Mientras repite mientras la condición siga siendo verdadera.

5 En total <- total + precio;, ¿qué es total?

El acumulador suma valores que pueden cambiar (precio). El contador suma siempre lo mismo.

B

Predicción de salidas

4 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este algoritmo?

Definir edad Como Entero;
edad <- 15;
Si edad >= 18 Entonces
    Escribir "Adulto";
Sino
    Escribir "Menor";
FinSi

15 es menor que 18: la condición es falsa y se ejecuta el Sino. La salida es Menor.

7 ¿Qué muestra este algoritmo?

Definir i Como Entero;
i <- 5;
Mientras i > 0 Hacer
    Escribir i;
    i <- i - 2;
FinMientras

El Mientras muestra 5, 3 y 1. Con 0 la condición deja de cumplirse.

8 ¿Qué muestra este algoritmo?

Definir i Como Entero;
Para i <- 1 Hasta 5 Con Paso 2 Hacer
    Escribir i;
FinPara

El Para empieza en 1, avanza de 2 en 2 y se detiene en 5.

9 ¿Qué muestra este algoritmo?

SubProceso Sumar(a, b)
    Escribir a + b;
FinSubProceso

Algoritmo Prueba
    Sumar(2, 3);
FinAlgoritmo

El subproceso recibe a = 2 y b = 3, y muestra 2 + 3 = 5.

Cómo se corrige la Parte C

Cada actividad vale 1 punto y se evalúa con una lista de requisitos. Si falta un requisito, se descuenta la parte proporcional. El corrector revisa la estructura del pseudocódigo; no ejecuta el programa.

Se revisaEjemplo
Declaración de variables con tipoDefinir precio Como Real;
Entrada y salidaLeer precio; · Escribir precio;
Condicional completoSi ... Entonces ... Sino ... FinSi
Bucle completoMientras ... Hacer ... FinMientras
Contadores y acumuladores inicializadosaprobadas <- 0; · suma <- 0;
Subproceso con parámetro y llamadaSubProceso MostrarCuadrado(numero) · MostrarCuadrado(3);

Antes de enviar

  • Declaré todas las variables con su tipo e inicialicé los contadores antes de usarlos.
  • Cerré cada Si, Mientras, Para y SubProceso.
  • Inicialicé los contadores antes de usarlos.
  • Probé mentalmente el algoritmo con un caso chico.
  • Revisé que las salidas coincidan con lo pedido.
C

Actividades de pseudocódigo

3 actividades · 1 punto cada una · se revisa la estructura del código.

10 Leé una estatura en metros. Si es menor que 1.60, mostrá Baja; si no, mostrá Alta. Usá Si … Entonces … Sino … FinSi.

VariablesLeer / EscribirCondicional

Ver pista

Declará estatura como Real, leela y comparala con 1.60 antes de escribir el mensaje.

Ver una solución de referencia 
Algoritmo ClasificarEstatura
    Definir estatura Como Real;
    Escribir "Ingresá la estatura:";
    Leer estatura;
    Si estatura < 1.60 Entonces
        Escribir "Baja";
    Sino
        Escribir "Alta";
    FinSi
FinAlgoritmo

11 Pedí 6 edades con un Mientras. Contá en mayores cuántas son 18 o más y sumá todas en suma. Mostrá los dos totales.

MientrasContadorAcumulador

Ver pista

Inicializá mayores y suma en 0. Repetí 6 vueltas, leé cada edad, sumala siempre y aumentá mayores solo si corresponde.

Ver una solución de referencia 
Algoritmo ResumenEdades
    Definir edad, mayores, suma, i Como Entero;
    mayores <- 0;
    suma <- 0;
    i <- 1;
    Mientras i <= 6 Hacer
        Escribir "Ingresá una edad:";
        Leer edad;
        suma <- suma + edad;
        Si edad >= 18 Entonces
            mayores <- mayores + 1;
        FinSi
        i <- i + 1;
    FinMientras
    Escribir "Mayores: ", mayores;
    Escribir "Suma: ", suma;
FinAlgoritmo
