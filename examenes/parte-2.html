A

Opción múltiple

6 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cuándo conviene usar un bucle Para?

El Para se usa cuando la cantidad de repeticiones es conocida. PSeInt inicializa, incrementa y corta el contador automáticamente.

2 ¿Cuántas veces se ejecuta el bloque de este bucle?

Para i <- 1 Hasta 5 Con Paso 1 Hacer
    Escribir i;
FinPara

El contador toma los valores 1, 2, 3, 4 y 5. El límite Hasta 5 se incluye, así que el bloque se ejecuta 5 veces.

3 ¿Cuándo se ejecuta el bloque de un Mientras?

La condición se revisa antes de cada vuelta. Si es verdadera, el bloque se ejecuta; si es falsa desde el principio, no se ejecuta ninguna vez.

4 ¿Qué falta si un Mientras se repite para siempre?

Todo Mientras necesita que su condición pueda volverse falsa. Si la variable de control no se actualiza dentro del bucle, la condición nunca cambia y el bucle no termina.

5 ¿Para qué sirve un SubProceso?

Un subproceso modulariza: agrupa una tarea con nombre propio y permite reutilizarla desde el algoritmo principal.

6 Si existe SubProceso Saludar(nombre), ¿qué hace la instrucción Saludar("Ana");?

La llamada ejecuta el subproceso. El valor "Ana" se copia en el parámetro nombre, que se comporta como una variable local.

B

Predicción de salidas

2 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

7 ¿Qué muestra este algoritmo?

Definir i Como Entero;
Para i <- 1 Hasta 4 Con Paso 1 Hacer
    Escribir i;
FinPara

El Para recorre 1, 2, 3 y 4. La salida es 1 2 3 4.

8 ¿Qué muestra este algoritmo?

Definir i Como Entero;
i <- 3;
Mientras i >= 1 Hacer
    Escribir i;
    i <- i - 1;
FinMientras

Muestra 3, luego 2 y luego 1. Cuando i llega a 0, la condición i >= 1 es falsa y el bucle termina. La salida es 3 2 1.

Ver pista

Declará numero y contador como Entero. Inicializá contador <- 0;. Si usás un Si dentro del bucle, inicializá también numero <- 1; para que la condición del Mientras tenga un valor. Repetí mientras numero <> 0, leé numero y contá solo si es distinto de 0.

Algoritmo ContarNumeros

    contador <- 0;
    numero <- 1;

        FinSi
    FinMientras
