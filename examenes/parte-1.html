A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Cuáles son las tres estructuras básicas de la programación estructurada?

La programación estructurada se organiza con secuencia (una instrucción tras otra), selección (Si–Entonces) e iteración (Mientras / Para).

2 Para guardar el precio de un producto con decimales, ¿cuál declaración es correcta en PSeInt estricto?

Real almacena números con parte decimal. Entero solo guarda números sin decimales. La forma correcta es Definir nombre Como Tipo;.

3 ¿Qué ocurre cuando el programa ejecuta Leer edad;?

Leer es una instrucción de entrada: espera que el usuario escriba un dato y lo almacena en la variable. Para mostrar información se usa Escribir.

4 ¿Qué estructura permite elegir entre dos caminos según una condición?

El Si evalúa una condición: si es verdadera ejecuta la rama del Entonces; si es falsa, la rama del Sino.

5 ¿Cuál de estas instrucciones corresponde a un contador?

Un contador suma siempre una cantidad fija, normalmente 1 (c <- c + 1). Un acumulador suma un valor variable (total <- total + precio).

B

Predicción de salidas

4 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este algoritmo?

Definir nota Como Entero;
nota <- 7;
Si nota >= 6 Entonces
    Escribir "Aprobado";
Sino
    Escribir "Desaprobado";
FinSi

7 es mayor o igual que 6, así que la condición es verdadera y se ejecuta la rama del Entonces: la salida es Aprobado.

7 ¿Qué muestra este algoritmo?

Definir n1, n2, n3, aprobados Como Entero;
n1 <- 8;
n2 <- 4;
n3 <- 10;
aprobados <- 0;
Si n1 >= 6 Entonces
    aprobados <- aprobados + 1;
FinSi
Si n2 >= 6 Entonces
    aprobados <- aprobados + 1;
FinSi
Si n3 >= 6 Entonces
    aprobados <- aprobados + 1;
FinSi
Escribir aprobados;

El contador arranca en 0. Suma 1 con la nota 8, no suma con la nota 4 y suma 1 con la nota 10. La salida es 2.

8 ¿Qué muestra este algoritmo?

Definir precio1, precio2, total Como Real;
precio1 <- 50;
precio2 <- 25.5;
total <- 0;
total <- total + precio1;
total <- total + precio2;
Escribir total;

El acumulador arranca en 0 y suma 50, luego 25.5. La salida es 75.5.

9 ¿Qué muestra este algoritmo?

Definir nombre Como Caracter;
Definir edad Como Entero;
nombre <- "Ana";
edad <- 20;
Escribir nombre, " tiene ", edad + 1, " años";

Se muestra el contenido de nombre, el texto entre comillas y el resultado de edad + 1 (21). La salida es Ana tiene 21 años.

Antes de enviar

  • Declaré todas las variables con su tipo.
  • Cerré cada Si con FinSi.
  • Inicialicé el contador y el acumulador antes de usarlos.
  • Verifiqué que el incremento del contador esté dentro del Si.
  • Revisé que las salidas coincidan con lo pedido.

VariablesLeer / EscribirCondicional
