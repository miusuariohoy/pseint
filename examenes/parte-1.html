A

Opción múltiple

5 preguntas · 1 punto cada una · marcá una sola respuesta.

1 ¿Qué característica define a un algoritmo estructurado?

La programación estructurada organiza el problema en secuencia, selección e iteración.

2 ¿Qué declaración guarda un valor Verdadero o Falso?

El tipo Logico solo admite Verdadero o Falso.

3 ¿Qué hace la instrucción Escribir "Hola";?

Escribir es salida: muestra el texto o el valor de una variable.

4 ¿Qué estructura elige una rama según una condición?

El Si evalúa la condición y ejecuta el Entonces o el Sino.

5 ¿Qué instrucción aumenta un contador en una unidad?

El contador suma siempre lo mismo: 1. La opción con precio sería un acumulador.

B

Predicción de salidas

4 algoritmos · 0,5 puntos cada uno · escribí lo que muestra cada uno.

6 ¿Qué muestra este algoritmo?

Definir nota Como Entero;
nota <- 4;
Si nota >= 6 Entonces
    Escribir "Aprobado";
Sino
    Escribir "Recupera";
FinSi

4 es menor que 6: se ejecuta el Sino. La salida es Recupera.

7 ¿Qué muestra este algoritmo?

Definir a, b, c, cuenta Como Entero;
a <- 3;
b <- 6;
c <- 9;
cuenta <- 0;
Si a > 5 Entonces
    cuenta <- cuenta + 1;
FinSi
Si b > 5 Entonces
    cuenta <- cuenta + 1;
FinSi
Si c > 5 Entonces
    cuenta <- cuenta + 1;
FinSi
Escribir cuenta;

Solo b y c superan 5: el contador queda en 2.

8 ¿Qué muestra este algoritmo?

Definir total Como Entero;
total <- 0;
total <- total + 10;
total <- total + 20;
total <- total + 5;
Escribir total;

El acumulador suma 10 + 20 + 5. La salida es 35.

9 ¿Qué muestra este algoritmo?

Definir nombre Como Caracter;
Definir edad Como Entero;
nombre <- "Luis";
edad <- 14;
Escribir nombre, ":", edad + 6;

Se muestra el nombre, dos puntos y el resultado de 14 + 6: Luis:20.

Cómo se corrige la Parte C

Cada actividad vale 1 punto y se evalúa con una lista de requisitos. Si falta un requisito, se descuenta la parte proporcional. El corrector revisa la estructura del pseudocódigo; no ejecuta el programa.

Antes de enviar

  • Declaré todas las variables con su tipo e inicialicé los contadores antes de usarlos.
  • Cerré cada Si con FinSi.
  • Inicialicé el contador y el acumulador antes de usarlos.
  • Verifiqué que el incremento del contador esté dentro del Si.
  • Revisé que las salidas coincidan con lo pedido.
