# Guía interactiva de PSeInt

Guía educativa autocontenida sobre **programación estructurada** con PSeInt.

## Contenido

- 9 temas de teoría organizados en acordeón.
- Pestañas de **Teoría** y **Ejercitación** dentro de cada tema.
- Ejercicios autocorregibles en la misma página.
- Autoevaluación teórica y actividad final con Parte A y Parte B.
- Panel de progreso con guardado automático en el navegador.

## Uso

Abrir `index.html` en cualquier navegador moderno. No requiere servidor, instalación ni conexión a internet.

## Publicación

El proyecto está listo para publicarse con **GitHub Pages** desde la rama `main` y la carpeta raíz del repositorio.
